# Chapter 1 요약: LangChain 기초

## 핵심 개념

### 1. LLM 기본 연결 (0.basic.ts)
- Google Gemini AI 모델 초기화
- 간단한 텍스트 응답 생성

### 2. 메시지 인터페이스 (1.langchain-interface.ts)
- SystemMessage와 HumanMessage를 활용한 대화 구성
- 시스템 프롬프트로 AI 행동 커스터마이징

### 3. 프롬프트 템플릿 (2.langchain-template.ts)
- PromptTemplate을 사용한 동적 프롬프트 생성
- 컨텍스트 기반 질의응답 구현

### 4. 채팅 프롬프트 템플릿 (3.langchain-chat-prompt-template.ts)
- ChatPromptTemplate으로 구조화된 대화 생성
- 시스템, 사용자 메시지 체계적 관리

### 5. 구조화된 출력 (4.answer-scheme.ts)
- Zod 스키마를 활용한 타입 안전 응답
- withStructuredOutput으로 예측 가능한 응답 형식 보장

### 6. Runnable 인터페이스 (5.runnable-interface.ts)
- invoke, batch, stream 메서드 활용
- 비동기 처리 패턴 구현

### 7. 스트리밍 (6.streaming-명령형.ts, 6-1.streaming-선언형.ts)
- 명령형: RunnableLambda와 generator 함수 활용
- 선언형: pipe 연산자로 간결한 스트리밍 구현

## 주요 학습 내용
- LangChain의 기본 구성 요소 이해
- 프롬프트 엔지니어링 기법
- 스트리밍과 구조화된 출력 활용법
- 체이닝을 통한 복잡한 워크플로우 구성
