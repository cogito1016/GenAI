# Chapter 2 요약: 문서 처리와 벡터 데이터베이스

## 핵심 개념

### 1. 문서 로딩과 청킹 (7.document-to-text-transform.ts)
- TextLoader로 마크다운 파일 로드
- RecursiveCharacterTextSplitter로 문서 분할
- 청크 크기와 오버랩 설정

### 2. 언어별 청킹 (8.chunk-with-metadata.ts)
- 마크다운 형식에 최적화된 분할
- fromLanguage 메서드로 언어별 처리
- 메타데이터 보존

### 3. 임베딩 생성 (9.embeddings.ts)
- GoogleGenerativeAIEmbeddings 모델 활용
- 텍스트를 벡터로 변환
- 768차원 벡터 생성

### 4. 통합 파이프라인 (10.7-8-9.ts)
- 문서 로드 → 청킹 → 임베딩 전체 과정
- 엔드투엔드 처리 구현

### 5. PGVector 도커 설정 (11.pgvector도커.md)
- PostgreSQL 벡터 확장 설치
- Docker 컨테이너 구성

### 6. 벡터 DB 저장 (12.vector-db.ts)
- PGVectorStore에 문서 저장
- 임베딩과 메타데이터 영구 저장

### 7. 유사도 검색 (13.vector-db-search.ts)
- similaritySearch로 관련 문서 검색
- k-NN 검색 구현

### 8. 멀티벡터 리트리버 (14.multi-vector-retrivers.ts)
- 요약 생성 및 저장
- 원본 문서와 요약 매핑
- InMemoryStore와 벡터스토어 조합
- 향상된 검색 정확도

## 주요 학습 내용
- 문서 처리 파이프라인 구축
- 벡터 데이터베이스 활용법
- 임베딩 기반 시맨틱 검색
- 멀티벡터 검색 전략으로 정확도 향상
